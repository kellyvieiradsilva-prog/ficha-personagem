# Ficha do Snoopy

Uma ficha de personagem digital interativa feita com **HTML** e **CSS**, apresentando o Snoopy, personagem icônico da turma Peanuts.

---

## 🌟 Tecnologias usadas
- HTML
- CSS

---

## 📌 Funcionalidades
- Apresentação do personagem com **descrição, curiosidades e personalidade**  
- Lista de **habilidades e características inspiradoras**  
- Imagem do personagem em destaque com **estilo responsivo**  
- Layout colorido e divertido, pensado para atrair atenção e inspirar criatividade
